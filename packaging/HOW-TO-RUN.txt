QUEDIN - law office manager
===========================

Requirements
  Windows 10 or 11
  .NET Framework 4.7.2 (included in Windows 10 1803 and later)
  SQL Server Express LocalDB and the sqlcmd utility

New installation with demo data
  1. Run setup-demo.cmd. It creates the QuedinDB database on (localdb)\MSSQLLocalDB
     and starts the application. Equivalent manual steps:

       sqlcmd -S "(localdb)\MSSQLLocalDB" -I -b -i database\create-database.sql
       app\LawyerProject.exe

  2. Sign in:

       admin  / Quedin2024   manager
       worker / Worker2024   worker

     The demo passwords are public. Change them, or create new accounts and
     deactivate the demo ones, before entering real data.

Upgrading an existing v1.3 database
  Do not run create-database.sql or setup-demo.cmd; they recreate the database.
  Run instead:

       sqlcmd -S "(localdb)\MSSQLLocalDB" -I -b -i database\upgrade-from-v1.3.sql

  then run database\security.sql again if it is in use.

Production use
  database\security.sql creates the QuedinWorker and QuedinManager roles.
  database\backup-nightly.cmd can be scheduled for a nightly backup.
  See the Deployment section of the README.

Documentation and source code
  https://github.com/shirushit/quedin-law-office-manager

הוראות התקנה

התקנה חדשה עם נתוני הדגמה:
  מריצים את setup-demo.cmd. הקובץ יוצר את מסד הנתונים QuedinDB ומפעיל את התוכנה.
  נכנסים עם admin / Quedin2024. יש להחליף את סיסמאות ההדגמה לפני עבודה עם נתונים אמיתיים.

שדרוג מגרסה 1.3:
  אין להריץ את create-database.sql או את setup-demo.cmd, כי הם יוצרים את המסד מחדש.
  מריצים את database\upgrade-from-v1.3.sql, שמשדרג את המסד בלי למחוק נתונים.
